Εφαρμογή παρακολούθησης προόδου μαθητών (PWA).

Σερβίρεται από GitHub Pages: https://domazakis.github.io/Students/

Τα δεδομένα των μαθητών ΔΕΝ βρίσκονται εδώ. Ζουν τοπικά στη συσκευή και συγχρονίζονται με το Dropbox της σχολής. Ο κώδικας είναι δημόσιος και δεν περιέχει προσωπικά στοιχεία.

Αρχεία:
index.html όλη η εφαρμογή
manifest.json εγκατάσταση ως εφαρμογή
sw.js λειτουργία χωρίς σύνδεση
icon.svg εικονίδιο
